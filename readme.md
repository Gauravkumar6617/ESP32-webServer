# 🚀 ESP32 Smart Web Control (MicroPython)

A simple IoT project using ESP32 and MicroPython to control an LED through a web browser.

---

## 📌 Features

- Wi-Fi connection using ESP32
- Web server running on ESP32
- Control LED ON/OFF from browser
- Mobile + laptop supported UI
- Clean HTML + CSS interface

---

## 🛠️ Hardware Required

- ESP32 Development Board
- Micro USB cable
- Laptop or PC
- Wi-Fi hotspot (mobile hotspot also works)

---

## 💻 Software Used

- MicroPython firmware for ESP32
- Thonny IDE (recommended)
- esptool (for flashing firmware)

Install Thonny:

```bash
sudo apt install thonny
```
